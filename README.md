# ShareMe → si è spostato

> 🇮🇹 **Lo standard ShareMe e il plugin che lo implementa vivono in un altro repository.**
> 🇬🇧 **The ShareMe standard and the plugin that implements it live in another repository.**

---

## 🇮🇹 Italiano

**ShareMe** è uno standard per condividere e adottare in modo consapevole le skill di Claude Code, insieme al plugin che lo implementa: `wrap` per chi condivide una skill, `unwrap` per chi ne riceve una scritta da altri.

Non vive qui. Sta dentro il marketplace di plugin AI, MAX:

### 👉 **[github.com/maxturazzini/aimax-marketplace](https://github.com/maxturazzini/aimax-marketplace)**

Per installarlo in Claude Code:

```
/plugin marketplace add maxturazzini/aimax-marketplace
/plugin install shareme@aimax-marketplace
```

Dopo l'installazione le due skill sono disponibili in qualsiasi sessione come `/shareme:wrap` e `/shareme:unwrap`.

Lo standard, le convenzioni di formato e un esempio completo stanno in [plugins/shareme/](https://github.com/maxturazzini/aimax-marketplace/tree/main/plugins/shareme).

> ⚠️ **Riferimenti superati.** Alcuni articoli e post indicano `maxturazzini/shareme` (questo repository) o `maxturazzini/aimax-skills` come sorgente da cui installare. Non funzionano: l'unico indirizzo valido è `maxturazzini/aimax-marketplace`.

---

## 🇬🇧 English

**ShareMe** is a standard for sharing and adopting Claude Code skills consciously, together with the plugin that implements it: `wrap` for whoever shares a skill, `unwrap` for whoever receives one written by someone else.

It does not live here. It lives inside the AI, MAX plugin marketplace:

### 👉 **[github.com/maxturazzini/aimax-marketplace](https://github.com/maxturazzini/aimax-marketplace)**

To install it in Claude Code:

```
/plugin marketplace add maxturazzini/aimax-marketplace
/plugin install shareme@aimax-marketplace
```

Once installed, both skills are available in any session as `/shareme:wrap` and `/shareme:unwrap`.

The standard, the format conventions and a full example are in [plugins/shareme/](https://github.com/maxturazzini/aimax-marketplace/tree/main/plugins/shareme).

> ⚠️ **Outdated references.** Some articles and posts point to `maxturazzini/shareme` (this repository) or `maxturazzini/aimax-skills` as the install source. Those do not work: the only valid address is `maxturazzini/aimax-marketplace`.
